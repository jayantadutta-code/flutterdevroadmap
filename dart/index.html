Part 4 Safety & Control (Null Safety)

4.1 Sound Null Safety

Types are non-nullable by default. Append ? for nullable variables.

Null SafetyString? nickname; // Nullable
late String bio; // Deferred init

void main() {
  bio = 'Dart Developer';
  print(nickname?.length ?? 0); // Null-aware & coalescing
}

Part 7 Concurrency (Isolates)

7.1 Isolates & Multithreading

Isolates are memory-isolated threads running on independent CPU cores.

Isolate.run()import 'dart:isolate';

int heavyTask(int count) {
  int sum = 0;
  for (int i = 0; i < count; i++) sum += i;
  return sum;
}

void main() async {
  int result = await Isolate.run(() => heavyTask(1000000));
  print('Background Isolate Result: $result');
}
